API

RAWDROP exposes a small REST API for uploading, listing, and deleting files. Base URL is your own deployment origin.

POST /api/upload

Upload a file via multipart/form-data with the field file.

{
  "success": true,
  "id": "a8K2mP9",
  "url": "https://example.com/raw/a8K2mP9",
  "filename": "script.lua",
  "size": 1024,
  "contentType": "text/plain",
  "extension": "lua"
}
GET /raw/:id

Returns the raw file with the stored Content-Type. No wrapper, no HTML.

GET /api/files

List uploaded files. Query params: limit, offset.

GET /api/files/:id

Get metadata for a single file.

DELETE /api/files/:id

Delete a file. If UPLOAD_TOKEN is set on the server, send header x-delete-token.

GET /api/stats

Server stats: file count, storage usage, uptime, status.

Documentation

HTML upload

<input type="file" id="file" />
<button onclick="uploadFile()">Upload</button>

<script>
async function uploadFile() {
  const file = document.getElementById("file").files[0];
  if (!file) return;

  const data = new FormData();
  data.append("file", file);

  const response = await fetch("https://example.com/api/upload", {
    method: "POST",
    body: data
  });

  const result = await response.json();
  if (result.success) console.log("RAW URL:", result.url);
}
</script>

cURL

curl -F "file=@./script.lua" https://example.com/api/upload

Node.js (Fetch, Node 18+)

import fs from "node:fs";

const file = new Blob([fs.readFileSync("./script.lua")]);
const form = new FormData();
form.append("file", file, "script.lua");

const res = await fetch("https://example.com/api/upload", {
  method: "POST",
  body: form
});

const data = await res.json();
console.log(data.url);

Python (Requests)

import requests

with open("script.lua", "rb") as f:
    r = requests.post(
        "https://example.com/api/upload",
        files={"file": ("script.lua", f, "text/plain")}
    )

print(r.json()["url"])

Limits & errors

  • Max upload size: 100 MB (configurable via MAX_FILE_SIZE).
  • Upload rate limit: 10 / minute / IP.
  • Blocked: executables, shell scripts, server-side languages (.php, .exe, .sh, …).
  • Allowed: text, code (.lua, .css, .json, .xml, …), images, audio, video, archives, fonts.
